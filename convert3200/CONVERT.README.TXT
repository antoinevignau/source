drive.	2/ Copy the file "Convert.Icons" from the "Icons" folder into the "Icons"	folder of your boot disk.	3/ Double-click on the "Convert.3200" icon to launch the program.	The program may be also launched from the diskette.___________________________________________________________________________Minimum System Requirements	The program requires at least 700KB of free memory.	It has been tested on Apple IIgs ROM 01 & ROM 03 versions.	It is compatible with System 6.x.	It is not intended to work under any multitasking environment.	Various video boards may not be 100% compatible with the program.Recommended System Requirements	Hard disk drive,	4mb of memory,	Accelerator card.___________________________________________________________________________Graphics File Formats Handled________________Importation- DYA			3200 colors		320*200- PaintWorks Gold		16, 256
